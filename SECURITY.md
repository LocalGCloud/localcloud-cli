# Security policy

Report suspected vulnerabilities privately to **info@local.cloud** with the
subject **Security report**, as described in the
[LocalCloud security policy](https://local.cloud/security/).

Include the affected component (CLI, runtime image, or website), its version
(`localcloud --version` or the runtime image digest), steps to reproduce, and
the impact you observed. Please do not include real credentials or customer
data, and test only against systems you own. Do not post vulnerability details
in public issues.

The CLI repository is public. Core runtime source remains private; reporting a
runtime issue does not require publishing that source. Send a sanitized
reproduction and the image version or digest instead.

See the [security page](https://local.cloud/security/) for release verification
instructions and the [standard contact record](https://local.cloud/.well-known/security.txt).
