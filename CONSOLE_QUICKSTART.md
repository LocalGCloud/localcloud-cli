# LocalCloud Console - Quick Start Guide

Get the LocalCloud Console up and running in 2 minutes.

## Prerequisites

- LocalCloud already installed and working
- Python 3.11+
- Node.js 16+ (only needed for building)

## Quick Start

### 1. Build the Frontend (One-Time Setup)

```bash
cd localcloud-console
npm install
npm run build
```

This creates the minified `dist/` files needed to run the console.

### 2. Start LocalCloud

```bash
localcloud start
```

Wait for the health check to pass (you'll see "LocalCloud is healthy").

### 3. Open the Console

In another terminal:

```bash
localcloud console
```

This starts the Flask server and automatically opens your browser to **http://localhost:9090**.

## What You Can Do

| Feature | Location | What It Does |
|---------|----------|-------------|
| **Dashboard** | Home tab | View all 13 services, health status, uptime |
| **Services** | Services tab | Start/stop services, see ports and status |
| **Logs** | Logs tab | View request logs in real-time, filter by service |
| **Data Browser** | Data tab | Preview data in Firestore, BigQuery, GCS, Spanner |
| **Settings** | Settings tab | Toggle dark/light mode, change refresh rate |

## Common Commands

```bash
# Start console on default port 9090
localcloud console

# Start on a different port
localcloud console --port 8888

# Start without opening browser
localcloud console --no-open

# Stop console
# Press Ctrl+C in the terminal

# Stop LocalCloud
localcloud stop
```

## Troubleshooting

| Problem | Solution |
|---------|----------|
| "Port 9090 in use" | Use `--port 8888` or `localcloud stop` then `localcloud start` again |
| Services show error | Check `localcloud status` - backend may not be healthy |
| Empty Data Browser | Create test data first (use CLI seed or SDK examples) |
| Browser won't connect | Check `curl http://localhost:9090/` in terminal |

## Architecture

```
Browser (http://localhost:9090)
    ↓ Solid.js SPA (26KB)
Flask Server (port 9090)
    ├─ Serves HTML/CSS/JS from dist/
    ├─ Handles API calls
    └─ Proxies to LocalCloud backend (port 8080)
```

## Files

- `localcloud-console/src/` - Frontend source (Solid.js + CSS)
- `localcloud-console/backend/` - Flask backend
- `localcloud-console/dist/` - Built output (generated by `npm run build`)
- `localcloud-console/README.md` - Full documentation
