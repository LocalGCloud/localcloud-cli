# LocalCloud

Official release distribution for [LocalCloud](https://local.cloud), a local Google Cloud emulator for development, testing, learning, and evaluation.

## Install

```sh
curl -fsSL https://local.cloud/install.sh | sh
```

Or with Homebrew:

```sh
brew install LocalGCloud/tap/localcloud
```

Docker Desktop, Colima, or Docker Engine must already be running. See each GitHub Release for checksummed standalone CLI archives and Sigstore verification bundles.
